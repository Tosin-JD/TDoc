## Adding New Assets

1. Place the file in `docs/assets/`
2. Document it in this README
3. Reference it in the relevant page (e.g., `architecture/overview.md`)

### Image Format

- PNG for screenshots and diagrams
- SVG for scalable diagrams (convert to PNG for Android docs)
